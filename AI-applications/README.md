## ⚙️ Getting Started

1. Clone the repository.
2. Navigate to the individual project directory.
3. Review the Python files and dependency instructions.
4. Create and activate a virtual environment for that project.
5. Install its required dependencies.
6. Configure API keys using environment variables where needed.
7. Run the relevant Python script or application.

Check each project's source code for its specific setup and execution instructions.

## 🔐 Security and Repository Hygiene

- Never commit API keys, passwords, or other secrets.
- Keep virtual environments and Python cache files out of Git.
- Avoid committing unnecessary generated outputs or large binary files.
- Retain research text files when they are required as project input.
