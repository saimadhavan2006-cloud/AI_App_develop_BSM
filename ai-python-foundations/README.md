## Getting Started

### Requirements
- Python 3.10 or later recommended
- A terminal or IDE such as Visual Studio Code

Check your Python installation:

```powershell
python --version
```

### Run an Exercise

Clone the repository and navigate to this folder:

```powershell
git clone https://github.com/saimadhavan2006-cloud/AI_App_develop_BSM.git
cd AI_App_develop_BSM/AI-python-foundations
```

Run a Python file using its relative path. For example:

```powershell
python day01/hello.py
```

To run a different exercise, replace the file path with the script you want to explore.

Some exercises may require user input. The weather application may require additional configuration or dependencies, depending on its implementation.
