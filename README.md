## ▶️ Getting Started

1. Browse the project folders.
2. Open the README for the project you want to explore.
3. Follow its setup instructions.
4. Install only the dependencies required for that project.
5. Configure API keys and environment variables locally when needed.

**Security note:** Never commit API keys, passwords, or other secrets. Avoid committing virtual environments, caches, local databases, and generated indexes unless a project specifically requires them.
