# AI App Development Portfolio

Welcome! This repository documents my journey in **Python, Generative AI, Retrieval-Augmented Generation (RAG), AI assistants, and backend development** through practical projects and experiments.

I focus on building applications that combine AI models, APIs, document processing, voice interfaces, and automation.

## 🧭 Learning Areas

- **Python Fundamentals:** Programming concepts, data structures, OOP, file handling, and problem-solving.
- **Generative AI:** AI-powered applications and experiments using language models.
- **RAG Applications:** Document-based question answering and retrieval systems.
- **AI Assistants:** Personal assistant applications with conversational and voice capabilities.
- **Backend Development:** REST APIs, testing, data validation, and database integration.
- **AI Automation:** Applying machine learning to practical workflows.

## ▶️ Getting Started

1. Browse the project folders above.
2. Open the README for the project you want to explore.
3. Follow that project's setup instructions.
4. Install only the dependencies required by that project.
5. Configure API keys and environment variables locally where required.

**Important:** Do not commit API keys, passwords, local databases, virtual environments, or generated model indexes.
